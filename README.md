# Security Camera Shop – Software Engineering Project

A university software engineering project developed as part of the COMP433 course at Birzeit University.

The project focuses on requirements analysis, UML modeling, and system architecture for a proposed online security camera store.

## Project Overview

The proposed system allows customers to browse security cameras, manage shopping carts, place orders, track purchases, and request support services.

## Project Deliverables

- User and system requirements analysis
- Use case specifications and scenarios
- UML activity and sequence diagrams
- Class and component diagrams
- System architecture and deployment design

## My Contributions

As part of a five-member team, I:

- Co-led user requirements analysis.
- Developed the scenario and use case specification for order tracking and history.
- Created activity and sequence diagrams for order tracking.
- Led the component diagram and contributed to reviewing system requirements and architecture.
